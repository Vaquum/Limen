# Support

Use the route that matches the request:

- bugs: open a bug report issue
- feature requests: open a feature request issue
- usage questions: open a support request issue
- vulnerabilities: use GitHub Security Advisories, not public issues

## Boundaries

Limen is research software. Maintainers do not provide investment advice, trading advice, exchange operations support, portfolio allocation advice, or live execution support.

For reproducible technical help, include:

- Limen version
- Python version and operating system
- command run
- manifest or minimal reproduction
- full error output
